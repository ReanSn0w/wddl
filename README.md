# webdav

Утилита для загрузки файлов с WebDav на локальную машину

## Очередь загрузок

Незавершённые задачи сохраняются в читаемом JSON-файле. Путь задаётся через
`QUEUE_FILE` или `--queue-file` и по умолчанию равен `./queue.json`.

Если очередь должна переживать пересоздание контейнера, размещайте файл на
постоянном volume. В Docker-образе используется `/data/queue.json` внутри уже
объявленного volume `/data`.
